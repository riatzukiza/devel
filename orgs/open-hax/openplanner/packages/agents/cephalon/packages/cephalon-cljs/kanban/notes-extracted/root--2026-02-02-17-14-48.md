## Draft Requirements
- **discover**: list channels
- **choose**: pick 1 channel deterministically (policy-based)
- **read**: fetch last 100 messages
- **summarize**: produce a short public summary message
- **remember**: store structured memory about that channel
- **persist**: save the full turn to disk/db
- **survive**: if tools fail or model outputs junk, it recovers and tries again next tick
- multi-agent orchestration
- cross-server “personality arcs”
- deep semantic retrieval
- complex task planning
- training / eval harness beyond basic metrics
