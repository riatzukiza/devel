## Capability vs. Policy — Resolved

**Capability** = a named bundle of tools + their default configurations that make a class of work *possible*. It implies access. You either have it or you don't. [ppl-ai-file-upload.s3.amazonaws](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/collection_23a4406f-5526-4a3e-9023-46480ab57089/25de6e96-1bc2-4cd2-9276-f14a5b83a60a/clojure-shadow-cljs-regex-synt-Ea7Yflk1RGG.lacjWPTG2w.md)

**Policy** = fine-grained environmental constraints on how you use a capability you already have. It narrows, never grants. [ppl-ai-file-upload.s3.amazonaws](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/collection_23a4406f-5526-4a3e-9023-46480ab57089/d6817952-0992-4be2-a808-bcc8e6685de9/let-s-review-our-contract-dsl-wp6t0Mw9T6OpkTnL2eDQBA.md)

If the actor lacks the capability, no policy is needed to prevent it — absence of capability is the lock. Policy is the deadbolt *inside* a door you're already allowed through. [ppl-ai-file-upload.s3.amazonaws](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/collection_23a4406f-5526-4a3e-9023-46480ab57089/25de6e96-1bc2-4cd2-9276-f14a5b83a60a/clojure-shadow-cljs-regex-synt-Ea7Yflk1RGG.lacjWPTG2w.md)

## Actor — Corrected

Actor is the template. Role(s) is what it brings to the table. Agent contract episodes can *append* or *override* roles for that run only. [ppl-ai-file-upload.s3.amazonaws](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/collection_23a4406f-5526-4a3e-9023-46480ab57089/d6817952-0992-4be2-a808-bcc8e6685de9/let-s-review-our-contract-dsl-wp6t0Mw9T6OpkTnL2eDQBA.md)

```clojure
{:actor/id           "discord-participant"
 :actor/kind         :agent
 :actor/role         :role/participant      ;; shorthand, singular
 ;; OR: :actor/roles [:role/participant :role/moderator]
 :actor/org-id       "open-hax"
 :actor/status       :active
 :actor/capabilities [:cap/read-messages
                      :cap/send-messages
                      :cap/emit-receipts
                      :cap/search-openplanner]
 ;; actor-level defaults — same keys as a contract, apply unless overridden
 :model              "gemma4:e4b"
 :thinking           :minimal
 :system-prompt      {:fn-ref :prompt/participant-baseline}}
```

The `:agent` sub-block is removed — those keys flatten onto the contract directly. ## Intent — Corrected

Fires after trigger, before execution. Must return truthy or contract is skipped. Default: always true. [ppl-ai-file-upload.s3.amazonaws](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/collection_23a4406f-5526-4a3e-9023-46480ab57089/d6817952-0992-4be2-a808-bcc8e6685de9/let-s-review-our-contract-dsl-wp6t0Mw9T6OpkTnL2eDQBA.md)

```clojure
{:contract/id    "intent.debounce"
 :contract/kind  :intent
 :contract/doc   "Skip if channel is too active for meaningful engagement."

 :intent/mode    :loose   ;; :loose | :strict | :custom

 :intent/check
 {:expr
  '(let [messages  (get-in ctx [:target :channel :messages])
         recent    (take-last 20 messages)
         chill?    (> (condition/average-ms-between recent) 2000)]
     (matches-intent chill?
       (when-not chill?
         "Channel too active for meaningful engagement right now.")))}}
```

`matches-intent` returns `{:proceed? bool :rationale string}`.  `:intent/mode` controls strictness: `:loose` means "warn but proceed if check errors," `:strict` means "abort on check error." [ppl-ai-file-upload.s3.amazonaws](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/collection_23a4406f-5526-4a3e-9023-46480ab57089/25de6e96-1bc2-4cd2-9276-f14a5b83a60a/clojure-shadow-cljs-regex-synt-Ea7Yflk1RGG.lacjWPTG2w.md)

## Fulfillment — Corrected With Two Modes

Two valid forms — deterministic expr (default) and judge (explicit). The prompts key only appears in `:judge` mode. [ppl-ai-file-upload.s3.amazonaws](https://ppl-ai-file-upload.s3.amazonaws.com/web/direct-files/collection_23a4406f-5526-4a3e-9023-46480ab57089/d6817952-0992-4be2-a808-bcc8e6685de9/let-s-review-our-contract-dsl-wp6t0Mw9T6OpkTnL2eDQBA.md)

### Deterministic (default)

```clojure
{:contract/id   "fulfillment.pr-ingested"
 :contract/kind :fulfillment
 :contract/doc  "Verify the PR was stored as a finding with evidence."

 :fulfillment/mode :strict

 :fulfillment/check
 {:expr
  '(let [receipts (get-in ctx [:run :receipts])
         findings (filter #(= (:kind %) :github/pr) receipts)]
     (fulfilled (and (seq findings)
                     (every? #(seq (:evidence-refs %)) findings))
                (when-not (seq findings)
                  "No :github/pr finding found in receipts.")))}}

{:contract/id   "fulfillment.correlations-emitted"
 :contract/kind :fulfillment
 :contract/doc  "Verify >= 1 correlation with weight >= 0.6 was emitted."

 :fulfillment/mode :strict

 :fulfillment/check
 {:expr
  '(let [corrs (filter #(>= (:weight % 0) 0.6)
                        (get-in ctx [:run :correlations]))]
     (fulfilled (seq corrs)
                (when-not (seq corrs)
                  "No high-confidence correlations found.")))}}

{:contract/id   "fulfillment.loose-json"
 :contract/kind :fulfillment
 :contract/doc  "Accept any well-formed response with a :signal key."

 :fulfillment/mode :loose

 :fulfillment/check
 {:expr
  '(fulfilled (some? (:signal result))
              (when (nil? (:signal result))
                "Response missing :signal key — re-run with output shape reminder."))}}
```

### Judge mode

```clojure
{:contract/id   "fulfillment.comedic-relief"
 :contract/kind :fulfillment
 :contract/doc  "The actor made the room laugh."

 :fulfillment/mode :judge

 :fulfillment/check
 {:actor-id  "discord-funny-judge"
  :model     "gemma4:31b"
  :thinking  :minimal
  :system    {:expr '(str "You are the funny police. Did "
                          (get ctx :actor-id)
                          " make anyone laugh in the last turn?")}
  :task      {:fn-ref :prompt/detect-laughter}}}
```

## The Execution Order, Complete

```
trigger fires (from :contract/uses "trigger.*")
  → intent check  (:intent/check expr → {:proceed? bool :rationale str})
    → [abort if :proceed? false]
  → actor resolved (actor-id → capabilities → roles → defaults)
  → contract roles merged (additional-roles / roles-override)
  → agent runs (model, system, task, tools from capabilities+policies)
    → hooks :before/hooks
    → LLM or deterministic execution
    → hooks :after/hooks (e.g. emit-receipt)
  → fulfillment check (:fulfillment/mode :strict|:loose → expr, or :judge → inline actor)
    → verdict: :held | :failed | :partial
    → new EventRecord emitted with verdict + receipt refs
  → mycology (if :failed or :partial, structured lesson appended)
```

That's the whole loop. Nothing in there requires disambiguation anymore.
