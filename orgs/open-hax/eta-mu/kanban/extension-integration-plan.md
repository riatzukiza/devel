## Identified Patterns for Macroization

### Pattern 1: State Management (HIGH frequency)

```clojure
;; Appears in 5/11 extensions
(def ^:const STATE-DIR (str HOME "/.pi/agent/state/<extension>"))
(def ^:const EVENTS-FILE (str STATE-DIR "/events.jsonl"))
(def ^:const STATUS-KEY "<extension-name>")
(def ^:const GLOBAL-KEY "__pi_<extension>_state__")

(defn get-state []
  (if-let [existing (aget js/globalThis GLOBAL-KEY)]
    existing
    (let [fresh #js {:enabled true ...}]
      (aset js/globalThis GLOBAL-KEY fresh)
      fresh)))
```

**Macro proposal:**
```clojure
(em/defstate <extension-name>
  :state-dir "<extension-name>"
  :events-file "events.jsonl"
  :initial-state {:enabled true}
  :status-key "<extension-name>")
```

### Pattern 2: Event Handlers (HIGH frequency)

```clojure
;; Appears in all extensions
(em/on "session_start"
  :handler (fn [_event ctx]
            (let [state (get-state)]
              (reset-state! state)
              (set-status ctx state))))

(em/on "session_shutdown"
  :handler (fn [_event ctx]
            (set-status ctx nil)))
```

**Macro proposal:**
```clojure
(em/defevents <extension-name>
  :on-session-start (fn [state] (reset-state! state) (set-status! ctx state))
  :on-session-shutdown (fn [ctx] (set-status ctx nil)))
```

### Pattern 3: Tool Parameter Schema (MEDIUM frequency)

```clojure
;; Repetitive parameter definition
:parameters {:action {:type "string"
               :enum ["status" "tail" "validate"]
               :description "..."}
           :path {:type "string" :description "..." :optional true}
           :lines {:type "integer" :min 1 :max 2000 :optional true}}
```

**Macro proposal:**
```clojure
(em/defparams
  {:action {:enum ["status" "tail" "validate"] :description "..."}
   :path {:optional true}
   :lines {:min 1 :max 2000 :optional true}})
```

### Pattern 4: JSONL Operations (MEDIUM frequency)

```clojure
;; File operations
(defn ensure-dir [dir]
  (.mkdirSync fs dir #js {:recursive true}))

(defn append-jsonl [file-path value]
  (ensure-dir (path/dirname file-path))
  (.appendFileSync fs file-path (str (js/JSON.stringify value) "\n") "utf8"))

(defn read-jsonl [file-path]
  (if-not (.existsSync fs file-path)
    #js []
    (->> (.split (.readFileSync fs file-path "utf8") #"\r?\n")
         (.filter (fn [x] x))
         (js/Array.from
          (.filter (.map lines
                    (fn [line]
                      (try (js/JSON.parse line)
                           (catch js/Error _ nil))))
                (fn [x] x))))))
```

**Already exists, could be moved to utility namespace**

### Pattern 5: UI Integration (MEDIUM frequency)

```clojure
;; UI helpers
(defn set-status [ctx state]
  (let [ui (when (aget ctx "hasUI") (aget ctx "ui"))
        set-status-fn (and ui (aget ui "setStatus"))]
    (when set-status-fn
      (.call set-status-fn ui STATUS-KEY (if state (format-status state) "")))))

(defn ui-notify [ctx message level]
  (let [ui (when (aget ctx "hasUI") (aget ctx "ui"))
        notify-fn (and ui (aget ui "notify"))]
    (when notify-fn
      (.call notify-fn ui message level))))
```

**Already exists, could be moved to utility namespace**

## Migration Priorities

### Phase 1: P1 Extensions (Image Processing)

**analyze-image.ts → analyze_image.cljs**
- Contract-based image analysis
- Vision API integration
- EDN contract loading
- Pure CLJS port, straightforward

**manipulate-image.ts → manipulate_image.cljs**
- Image operations (crop, resize, pad, grayscale, blur)
- Uses analyze_image output for cropping
- Pure CLJS, straightforward

### Phase 2: P2 Extensions (Desktop Integration)

**apply-patch.ts → apply_patch.cljs**
- Multi-file patch application
- Codex-style format parsing
- Complex but self-contained
- Useful for GPT model compatibility

**desktop-ops.ts → desktop_ops.cljs**
- Screenshot capture
- Firefox/xdg-open integration
- i3 window manager integration
- KDE-specific (Spectacle)

### Phase 3: P3 Extensions (Advanced)

**webpage-markdown.ts → webpage_markdown.cljs**
- Already have `websearch_open_hax` as reference
- Duplicate functionality, merge or enhance

**skill-graph-aco.ts → skill_graph_aco.cljs**
- Ant Colony Optimization for skill recommendations
- Ollama embedding API integration
- Complex state management
- Would benefit from macros
