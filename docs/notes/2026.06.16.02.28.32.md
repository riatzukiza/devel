## Task: Restructure bitch-tracker to eta-mu-sol architecture


### Context
This codebase is a lazy direct-from-JS rewrite of a BetterDiscord plugin + nbb bot
that tracks moderation label reactions and flushes events to OpenPlanner.
It has no schemas, no validation, raw `#js {}` state, duplicated `jget`/`str`/`or`
access chains everywhere, and all domain logic collapsed into two monolith files
(`plugin.cljs` and `bot/socket.cljs`).

### Architecture target (eta-mu-sol house rules)
Four strictly separated namespace categories:

  domain.*   — pure business logic, no I/O
  infra.*    — effectful transport/persistence layer
  shape.*    — structure-only morphisms, pure, domain-agnostic
  law.*      — Malli schemas + boundary contracts, no I/O

### Deliverables (pure layer only — no infra changes yet)

Produce the following new files from scratch.
Each file must:
- have a docstring on the ns
- have docstrings on every public fn
- produce zero clj-kondo warnings (`:missing-docstring`, `:unused-value`,
  `:shadowed-var`, `:unsorted-required-namespaces`)
- not use `utils` as a namespace segment
- not use broad `:refer :all`

#### 1. `src/bitch_tracker/law/schemas.cljc`
Malli schemas for every boundary-crossing shape:
  - `OpenPlannerEventId`  (regex: `discord:<guild>:<channel>:<message>`)
  - `Attachment`
  - `EventMeta`
  - `OpenPlannerEvent`    (closed map, schema-version 1)
  - `LabelPayload`        (closed map)
  - `BotConfig`           (closed map, all required keys typed)
  - `WatchEntry`          (closed map, :pattern is a RegExp)
  - `SocketMessage`       (closed map, discriminated by :op keyword)

#### 2. `src/bitch_tracker/law/contracts.cljc`
Boundary validators built on `law.schemas`:
  - `valid-open-planner-event!`  — throws ex-info on violation
  - `valid-label-payload!`
  - `valid-bot-config!`
  - `valid-socket-message!`
  Each validator must emit a human-readable explanation via `malli.error/humanize`.

#### 3. `src/bitch_tracker/shape/coerce.cljs`
Extract every `(str (or (aget …) (aget …) ""))` pattern from
`plugin.cljs` and `bot/socket.cljs` into named, documented coercer fns:
  - `message-id`
  - `channel-id`
  - `guild-id`        (resolves from payload OR channel arg)
  - `emoji-str`
  - `author-id`
  - `attachment->map` (JS attachment object → Clojure map matching Attachment schema)
  - `js-seq`          (any JS iterable → Clojure seq)
No domain logic. No I/O. Pure structural morphisms only.

#### 4. `src/bitch_tracker/domain/label.cljs`
Pure label-count state machine. Replaces the `js/Map` + `js/Set` state in `plugin.cljs`.
State shape: `{:counts {user-id -> int} :messages {user-id -> #{message-id}} :labeled #{message-id}}`
  - `empty-state`
  - `add`             — returns new state; idempotent on duplicate message-id per user
  - `remove-label`    — returns new state; floor at 0
  - `count-for`
  - `labeled?`
  - `threshold-crossed?` — true when *current* count is strictly below threshold
                            (i.e. adding would cross it)

#### 5. `src/bitch_tracker/domain/watchlist.cljs`
Extract from `bot/config.cljs` and `bot/socket.cljs`:
  - `compile-watch-entry` — string pattern + label → WatchEntry map (regex compiled)
  - `compile-watch-entries` — seq of raw config entries → seq of WatchEntry
  - `moderation-hit?`     — WatchEntry × message-text → boolean
  - `moderation-hits`     — seq of WatchEntry × message-text → seq of matching WatchEntry

#### 6. `src/bitch_tracker/domain/dedup.cljs`
Extract pure logic from `bot/dedup.cljs`. State is a plain Clojure map.
  - `empty-store`
  - `seen?`           — store × id × ttl-ms × now-ms → boolean
  - `add`             — store × id × now-ms → new-store
  - `evict-expired`   — store × now-ms → new-store (removes entries older than their TTL)
No filesystem access. No `js/Date`. Callers pass `now-ms` explicitly.

### Tests
For each domain namespace, produce a co-located test file using `cljs.test`:
  `test/bitch_tracker/domain/label_test.cljs`
  `test/bitch_tracker/domain/watchlist_test.cljs`
  `test/bitch_tracker/domain/dedup_test.cljs`

Each test file must have at minimum:
  - one "happy path" test per public fn
  - one boundary/edge-case test per public fn
  - tests are `deftest` (not async — all fns are pure)
  - zero clj-kondo warnings

### Constraints
- Do NOT touch `plugin.cljs`, `bot/socket.cljs`, `bot/config.cljs`, or any infra file.
  This PR is pure-layer only.
- All ClojureScript targets nbb (Node, no browser DOM available).
- `law/schemas.cljc` and `law/contracts.cljc` must be `.cljc` (used by both Clojure tests
  and ClojureScript runtime).
- Use Malli `0.16+` API. Do not use deprecated `m/schema` constructor form.
- No `core.async`. No Promises. All fns are synchronous.
- `clj-kondo` config for any new macros must be registered in `.clj-kondo/config.edn`
  on the same commit.

### Definition of done
  `clj-kondo --lint src/ test/` exits 0 with zero warnings.
  `bb test` (or `npx shadow-cljs compile test`) exits 0.
  Every public function in `domain.*` and `shape.*` has a passing test.
  Every schema in `law.*` has at least one `m/validate` assertion in a test.
